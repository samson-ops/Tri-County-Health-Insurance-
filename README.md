# Tri State Affordable Health Insurance — home page

Static corporate home page. Open `index.html` in a browser; images are in `img/`.

Before going live, replace the items tagged **Placeholder** on the page (phone number, address, hours, service-area state names) and fill the accreditation badge slots only with credentials the company holds. The plan finder and provider search forms are front-end only and need to be connected to real quoting and directory systems.
